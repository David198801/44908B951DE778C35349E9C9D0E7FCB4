# PCGamingWiki

对于任何 Steam 上的老游戏无法运行，强烈建议在折腾前访问 **[PCGamingWiki](https://www.pcgamingwiki.com/)**。

- 在搜索框输入游戏名字。
- 页面会详细列出该游戏在现代 Windows 10/11 系统上的所有已知问题和修复方法（Fixes）。
- 它会明确告诉你这个游戏是否推荐使用 DXVK、dgVoodoo2，还是需要某些社区制作的修复补丁（如 SilentPatch）。
