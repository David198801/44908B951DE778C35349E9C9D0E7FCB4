`uv` 是一个用 Rust 编写的极速 Python 包和项目管理工具，旨在替代 `pip`、`pipenv`、`poetry` 等传统工具。

### 安装 uv

安装 `uv` 主要有两种方式，推荐使用官方脚本进行独立安装。

#### 方法一：使用官方安装脚本（推荐）

这种方式会独立安装 `uv`，避免与系统 Python 环境产生依赖冲突。

*   **Windows (PowerShell)**:
    ```powershell
    powershell -ExecutionPolicy ByPass -c "irm https://astral.sh/uv/install.ps1 | iex"
    ```
    
*   **macOS / Linux**:
    ```bash
    curl -LsSf https://astral.sh/uv/install.sh | sh
    ```
    

#### 方法二：使用 pip 安装

这种方式会将 `uv` 安装到当前的 Python 环境中。

```bash
pip install uv
```


如果在国内网络环境下速度较慢，可以在 `pip` 命令后临时指定国内镜像源：
```bash
pip install uv -i https://repo.huaweicloud.com/repository/pypi/simple
```


安装完成后，可运行以下命令验证是否成功：
```bash
uv --version
```

### 配置 uv 换源 (国内镜像加速)

`uv` **不会自动读取** `pip` 的镜像源配置，需要单独设置。换源主要涉及两个方面：

1.  **PyPI 源**：加速下载 Python 第三方包（如 `uv add numpy`）。
2.  **CPython 代理**：加速下载 Python 解释器本身（如 `uv python install 3.12`）。

有以下几种配置方式：

#### 方法一：修改全局配置文件 (一劳永逸)

这是最推荐的方式，配置一次，对所有项目生效。

1.  **找到或创建配置文件**：`uv` 的全局配置文件名为 `uv.toml`，位于：
    *   **Windows**: `%APPDATA%\uv\uv.toml` (通常是 `C:\Users\你的用户名\AppData\Roaming\uv\uv.toml`)
    *   **macOS / Linux**: `~/.config/uv/uv.toml`

    如果 `uv` 文件夹或 `uv.toml` 文件不存在，请手动创建。

2.  **编辑配置文件**：用文本编辑器打开 `uv.toml` 文件，将以下内容复制进去。这个配置同时包含了 PyPI 源和 CPython 代理的加速设置。

    ```toml
    # 加速 Python 解释器下载（对应 `uv python install`）
    python-install-mirror = "https://cnb.cool/astral-sh/python-build-standalone/-/releases/download/"
    
    # 加速 PyPI 包下载（对应 `uv add` / `uv pip install`）
    [[index]]
    url = "https://mirrors.cloud.tencent.com/pypi/simple"
    default = true
    ```
    

    你可以将 `url` 替换为其他镜像源，详见下文。

#### 方法二：设置环境变量 (临时或永久)

这种方式仅对 PyPI 源生效。

*   **临时生效 (仅对当前终端会话)**:
    *   **Windows (PowerShell)**:
        ```powershell
        $env:UV_INDEX_URL = "https://pypi.tuna.tsinghua.edu.cn/simple"
        ```
        
    *   **macOS / Linux**:
        ```bash
        export UV_INDEX_URL=https://pypi.tuna.tsinghua.edu.cn/simple
        ```
        

*   **永久生效**:
    *   **Windows**: 在“系统属性” -> “高级” -> “环境变量”中，新建一个系统或用户变量，变量名为 `UV_INDEX_URL`，变量值为镜像源地址。
    *   **macOS / Linux**: 将 `export` 命令添加到你的 shell 配置文件中（如 `~/.bashrc` 或 `~/.zshrc`）。
        ```bash
        echo 'export UV_INDEX_URL="https://pypi.tuna.tsinghua.edu.cn/simple"' >> ~/.zshrc
        source ~/.zshrc
        ```
        

#### 方法三：针对单个项目配置

在项目根目录的 `pyproject.toml` 文件中添加以下内容：
```toml
[tool.uv]
index-url = "https://pypi.tuna.tsinghua.edu.cn/simple/"
```


#### 方法四：命令行临时指定

在执行命令时通过参数临时指定源，仅对当前命令生效。
```bash
uv add --default-index https://pypi.tuna.tsinghua.edu.cn/simple requests
```
