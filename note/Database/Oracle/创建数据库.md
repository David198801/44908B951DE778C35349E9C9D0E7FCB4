# 1. 创建orcl

最简单的做法是用 `dbca` 创建。

**先确认环境**

- 以 `oracle` 用户登录
- 确认这几个变量正确：

```bash
echo $ORACLE_BASE
echo $ORACLE_HOME
echo $ORACLE_SID
```

- 常见应类似：

```bash
ORACLE_BASE=/u01/app/oracle
ORACLE_HOME=/u01/app/oracle/product/19.3.0/db_1
ORACLE_SID=orcl
```

如果 `ORACLE_SID` 还没设，先执行：

```bash
export ORACLE_BASE=/u01/app/oracle
export ORACLE_HOME=/u01/app/oracle/product/19.3.0/db_1
export ORACLE_SID=orcl
export PATH=$ORACLE_HOME/bin:$PATH
```

**推荐方式：用 DBCA 静默创建**
先建目录：

```bash
mkdir -p /u01/app/oracle/oradata
mkdir -p /u01/app/oracle/fast_recovery_area
mkdir -p /u01/app/oracle/admin/orcl/adump
chown -R oracle:oinstall /u01/app/oracle
```

然后执行创建命令：

```bash
dbca -silent -createDatabase \
-templateName General_Purpose.dbc \
-gdbname orcl \
-sid orcl \
-createAsContainerDatabase false \
-sysPassword Oracle123 \
-systemPassword Oracle123 \
-datafileDestination /u01/app/oracle/oradata \
-recoveryAreaDestination /u01/app/oracle/fast_recovery_area \
-storageType FS \
-characterSet ZHS16GBK \
-nationalCharacterSet AL16UTF16 \
-memoryMgmtType auto_sga \
-totalMemory 8192 \
-emConfiguration NONE
```

说明几点：

- `-gdbname orcl` 是数据库名
- `-sid orcl` 是实例名
- `-createAsContainerDatabase false` 表示建传统非 CDB，最省事
- `Oracle123` 只是示例密码，建议你换成自己的
- `totalMemory 8192` 表示分配 8G 内存，可按机器实际调整

创建成功后，通常会自动生成：

- 数据文件目录：`/u01/app/oracle/oradata/ORCL` 或类似目录
- 参数文件：`/u01/app/oracle/product/19.3.0/db_1/dbs/spfileorcl.ora`
- 审计目录：`/u01/app/oracle/admin/orcl/adump`

**创建后验证**
执行：

```bash
sqlplus / as sysdba
```

在 SQL*Plus 里：

```sql
select name, open_mode from v$database;
select instance_name, status from v$instance;
```

如果数据库没自动打开，也可以：

```sql
startup;
```

# 2. 改pga大小
```sql
ALTER SYSTEM SET pga_aggregate_limit = 10G SCOPE=BOTH;
```

# 3. 改允许连接级别

cd $ORACLE_HOME/network/admin目录下 新建文件sqlnet.ora

```sql
SQLNET.ALLOWED_LOGON_VERSION_SERVER=11
SQLNET.ALLOWED_LOGON_VERSION_CLIENT=11
```

**不需重启数据库和监听，新的连接就可以正常连接了。**

# 4. 然后必须修改一次密码！！

```sql
ALTER USER 你的用户名 IDENTIFIED BY 你的密码;
```

```sql
SELECT username, password_versions FROM dba_users WHERE username = '你的用户名';
```
